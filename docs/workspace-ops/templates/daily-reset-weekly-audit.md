# Daily Reset & Weekly Audit

The two rituals that keep the space clean past week one. Print both; post the daily reset at each
station and the weekly audit at the issue window.

---

## Daily reset — 5 minutes, every session

Run it before anyone leaves. The Parts Captain owns their station; everyone pitches in on shared
areas.

- [ ] **Tools home.** Every tool back on its shadow board / in its foam slot — no empty silhouettes.
- [ ] **Team bin closed** and on the station; loose parts back in the right bin.
- [ ] **Line-side kanban bins topped up**; any empty bin moved to the refill shelf.
- [ ] **A-items accounted for** — anything checked out today is returned or logged (brains, batteries, shared tools).
- [ ] **Batteries off the charger** or safely stored; nothing charging unattended.
- [ ] **Floor & aisles clear**; trash/recycling emptied; benches wiped.
- [ ] **Shortage Board updated** — flag anything running low.

!!! tip "Make it 5 minutes, not 20"
    A daily reset only works if it's short and non-negotiable. Set a timer, make it the last thing
    every session, and keep the list to what you can actually check in five minutes.

---

## Weekly audit — 10 minutes

A quick walk with a score. Post the result on the scoreboard by team.

### 5S scorecard (rate each 0–4)

| S | Looks like… | Score |
|---|---|---|
| **Sort** | No junk/red-tag buildup; only needed items present | ☐ |
| **Set in order** | Everything in its addressed home; labels match contents | ☐ |
| **Shine** | Clean floor, benches, tools; nothing blocking egress | ☐ |
| **Standardize** | Labels, colors, and SOPs consistent everywhere | ☐ |
| **Sustain** | Daily resets actually happening; owners engaged | ☐ |
| | **Total (/20)** | |

### Also each week

- [ ] **Cycle count a slice** — A-items monthly, B quarterly, C by exception (only when a min/max flag trips). Count whatever's due this week; reconcile the sheet.
- [ ] **Check min/max flags** → build the **reorder list**.
- [ ] **Battery health** — inspect a rotation of packs; retire any at end-of-life per the log.
- [ ] **Shadow boards** — any tool missing all week? Investigate.
- [ ] **Post the scoreboard** — cleanest station, best BOM accuracy, tools-returned streak.

## Scoreboard (post it where everyone sees)

| Week | Team 1 | Team 2 | Team 3 | Team 4 | 5S total /20 | Notes |
|---|---|---|---|---|---|---|
| e.g. Wk 6 | 🟢 | 🟡 | 🟢 | 🟢 | 17 | Blue: 2 tools out at reset |

!!! example "Industry example — visual management"
    The point of the scorecard and scoreboard is to make the invisible visible. A number on a wall
    that ticks down creates gentle, self-correcting pressure — teams protect a streak and fix their
    own station before the audit, which is exactly the behavior you want to become automatic.
