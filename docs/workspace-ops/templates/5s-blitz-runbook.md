# 5S Blitz Runbook

A concentrated **sort → purge → inventory** push to reset the space in one or two days, instead
of nibbling for months. Print this and run the day from it.

!!! abstract "Before the day"
    - Photograph the "before" (every wall/shelf/table).
    - Sketch the floor plan; decide the back-room boundary and how it locks.
    - Recruit 4–8 people; name a **Stockroom Lead** and 2–3 **sorters**.
    - Announce a **parts freeze**; ask every team to bring their loose parts to be inventoried.
    - Gather: bins/totes, label printer or Avery labels, colored tape, **red tags**, trash + recycling bins, gloves, folding sort tables, a laptop/tablet with the [inventory sheet](inventory-master.csv) open.
    - Stage a **Red-Tag Holding Area** (`RT` zone — a corner or labeled totes).

---

## Hour-by-hour (a one-day version — scale to your crew)

| Time | Block | What happens |
|---|---|---|
| 0:00–0:30 | **Kickoff** | Walk the plan, assign roles, set the category buckets on folding tables, safety brief (batteries, blades) |
| 0:30–2:30 | **Sort wave 1** | Clear one shelf/zone at a time → sort contents into category buckets (STR/MOT/WHL/ELE/PNE/HW/CON/BB/TOOL) → red-tag anything questionable |
| 2:30–3:00 | **Break + battery triage** | Pull out all batteries; inspect; puffed/damaged → safe disposal path |
| 3:00–5:00 | **Sort wave 2** | Finish remaining shelves/zones; consolidate duplicate piles |
| 5:00–5:30 | **Lunch** | — |
| 5:30–7:30 | **Inventory the Keep pile** | Count into the sheet using **ABC** (A=serialize, B=exact, C=weigh/estimate + min/max). Label bins with part # + QR as you go |
| 7:30–8:00 | **Stage locations** | Rough-place categories into their back-room zones (final layout is Phase 3) |
| 8:00–8:30 | **Reset & photo** | Clean floor, take "after" photos, log what's left in the red-tag area, set the **30-day red-tag deadline** |

---

## The Keep/Toss decision (say it out loud on the day)

Touch each item **once**. One decision:

| Decision | When | Where it goes |
|---|---|---|
| **Keep** | In use, good condition, we clearly need it | Category bucket → inventory → home |
| **Relocate** | Belongs, but somewhere else (front vs back) | Its correct zone |
| **Repair** | Fixable and worth fixing | Repair bin (with a note) |
| **Recycle** | Dead but recyclable (metal, e-waste) | Recycling/e-waste |
| **Trash** | Dead, not recyclable | Trash |
| **Red-tag** | "Might need it," unsure, unclaimed | Red-Tag Holding Area, dated |

!!! danger "Batteries are not normal trash"
    Swollen/puffed/hot LiPo or V5 batteries go to a **fire-safe container** immediately and then to
    proper battery/e-waste disposal — never the trash, never "one more use."

---

## Red-tag rules

- Every red-tagged item gets a tag: **what · who tagged it · date**.
- It sits in the **`RT` holding area**, visible.
- **Deadline: 30 days.** If nobody claims or uses it by then, it leaves (recycle/trash/donate).
- Schedule the **Red-Tag Day** on the calendar *now*, before you forget.

!!! example "Why red-tag instead of arguing"
    On blitz day you won't win every "but we might need this someday" debate, and you shouldn't
    try. Red-tagging converts the argument into a **test with a deadline**: if it's truly needed,
    someone will pull it from the holding area within a month. If not, the shelf was right.

---

## End-of-blitz checklist

- [ ] Every Keep item is in a labeled bin with a part # (QR if possible) and a home zone.
- [ ] The inventory sheet has a row for everything counted (A/B exact, C estimated).
- [ ] All batteries inspected; damaged ones removed to safe disposal.
- [ ] Red-tag area logged and dated; Red-Tag Day on the calendar.
- [ ] Floor clear, aisles open, "after" photos taken.
- [ ] Trash/recycling/e-waste hauled out.
- [ ] Next step scheduled: **Phase 3 — lay out zones & build shadow boards**.
